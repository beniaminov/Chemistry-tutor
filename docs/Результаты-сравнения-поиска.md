## Baseline и ограничения

- Baseline сохранён в `tests\data\retrieval_baseline.json`.
- Оценка page-level: попадание любого фрагмента с ожидаемой страницы считается релевантным. Chunk ID разрешаются по `evidence_terms` и используются только для проверки, что опора существует в корпусе.
- Формулы проверяются regex-вариантами с учётом типичных ошибок OCR; это не заменяет ручную сверку по изображению страницы.
- Набор проверяет retrieval, а не качество ответа Qwen. Отказы, цитирование и устойчивость к инъекциям оцениваются на этапе 3.
- Онтологические URI в payload пока пусты, поэтому вопросы типа `ontology` проверяют только текстовую опору; связь с RDF — этап 4.
- Контрольный набор составлен по OCR-тексту и сверен с оглавлением и выборочными страницами PDF; перед изменением PDF его нужно перепроверить.
